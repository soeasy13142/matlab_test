# 作业二 · 周期信号的傅里叶级数

周期信号的一个周期波形为

```
        ⎧ +1,  0 ≤ t < T/2
f(t) =  ⎨
        ⎩ -1,  T/2 ≤ t < T
```

周期为 `T`，基频 `ω₀ = 2π/T`。

## 一、傅里叶级数展开解析式

三角形式的傅里叶级数为

```
f(t) = a₀/2 + Σ [ aₙ·cos(nω₀t) + bₙ·sin(nω₀t) ]     n = 1, 2, 3, …
```

### 1. 先用对称性判断哪些项一定为零

- **奇函数**：周期延拓后 `f(-t) = -f(t)`（`t ∈ (-T/2, 0)` 段取值 `-1`，与 `t ∈ (0, T/2)`
  段的 `+1` 关于原点反对称）。奇函数不含余弦项，故 `a₀ = 0`，全部 `aₙ = 0`。
- **半波对称**：`f(t + T/2) = -f(t)`。这一条会消掉全部偶次谐波，只剩奇次。

两条对称性合起来说明：展开式里只有奇次正弦项。下面按定义严格算一遍，确认没有漏项。

### 2. 三个系数的积分

**直流分量**（注意一个周期内正负各占一半）：

```
a₀ = (2/T)∫₀ᵀ f(t) dt = (2/T)[ ∫₀^{T/2} 1·dt + ∫_{T/2}^{T} (-1)·dt ]
   = (2/T)( T/2 - T/2 ) = 0
```

**余弦项系数**：

```
aₙ = (2/T)[ ∫₀^{T/2} cos(nω₀t) dt − ∫_{T/2}^{T} cos(nω₀t) dt ]
   = (2/T)·(1/(nω₀))·{ [sin(nω₀t)]₀^{T/2} − [sin(nω₀t)]_{T/2}^{T} }
   = (2/T)·(1/(nω₀))·{ sin(nπ) − [ sin(2nπ) − sin(nπ) ] }
   = 0                                     （n 为整数时 sin(nπ) = sin(2nπ) = 0）
```

**正弦项系数**：

```
∫₀^{T/2}   sin(nω₀t) dt = (1 − cos nπ) / (nω₀)
∫_{T/2}^{T} sin(nω₀t) dt = (cos nπ − 1) / (nω₀)

bₙ = (2/T)[ ∫₀^{T/2} sin(nω₀t) dt − ∫_{T/2}^{T} sin(nω₀t) dt ]
   = (2/T) · 2(1 − cos nπ) / (nω₀)
```

代入 `nω₀ = 2πn/T`、`cos nπ = (−1)ⁿ`：

```
bₙ = 2(1 − (−1)ⁿ) / (πn)  =  ⎧ 4/(πn),  n 为奇数
                            ⎩ 0,        n 为偶数
```

### 3. 结果

```
           4   ∞      1
f(t)  =   ──  Σ    ────── · sin(nω₀t)          ω₀ = 2π/T
           π  n=1,3,5  n

          4 ⎡             1              1               ⎤
      =   ── ⎢ sin ω₀t + ── sin 3ω₀t + ── sin 5ω₀t + …   ⎥
          π ⎣             3              5               ⎦
```

幅值按 `1/n` 衰减，只含奇次谐波，这是双极性矩形波的标准展开式。

### 4. 数值核验

推导不靠手算结论。用基础 MATLAB 的 `trapz` 把 `[0, T/2]` 与 `[T/2, T]` 两段分开积分
（跳变点处切开，避免 `trapz` 跨越间断点），对 `n = 1…12` 逐项计算：

| n | 数值积分 aₙ | 数值积分 bₙ | 解析值 |
|---|---|---|---|
| 1 | 1.2e−16 | 1.273240 | 4/π = 1.273240 |
| 2 | 1.4e−17 | 0.000000 | 0 |
| 3 | 1.1e−16 | 0.424413 | 4/(3π) = 0.424413 |
| 4 | 0 | 0.000000 | 0 |
| 5 | 1.8e−16 | 0.254648 | 4/(5π) = 0.254648 |
| … | … | … | … |

`a₀ = 0`，全部 `aₙ` 都是 1e−16 量级的机器零，`bₙ` 与 `4/(πn)`（奇次）、`0`（偶次）
逐位吻合。解析式成立。

## 二、N 取 3、10、50、100 的差别及原因（研究与思考）

先说口径。题目要求「取 `2N+1` 项近似式」，按三角形式
`f(t) = a₀/2 + Σ_{n=1}^{N}[aₙcos(nω₀t) + bₙsin(nω₀t)]` 数，截断到 `n = N` 恰好是
`1 + 2N = 2N+1` 项，所以 N 就是保留的最高谐波次数。本题的矩形波只有奇次正弦项非零，
实际留下的是 `1、3、5、…` 中不超过 N 的奇次项，共 `ceil(N/2)` 项。

脚本 `hw02_fourierSeries.m` 实测的四组指标（理想矩形波为参照）：

| N | 最高谐波 | 保留项数 | 过冲峰值 | 全区间 RMSE | 跳变点 0.02 s 外的最大偏差 |
|---|---|---|---|---|---|
| 3 | 3 | 2 | 1.2004 | 0.315274 | 0.684184 |
| 10 | 9 | 5 | 1.1823 | 0.201066 | 0.266349 |
| 50 | 49 | 25 | 1.1791 | 0.090216 | 0.097444 |
| 100 | 99 | 50 | 1.1790 | 0.063942 | 0.050194 |

### 1. 平缓段与跳变沿

N=3 时波形还是圆钝的波浪，N=10 已能看出矩形轮廓，N=50、100 的平顶段几乎与理想波形
重合，跳变沿也从斜坡变成了陡壁。

这是因为级数在波形连续的点上逐点收敛于 `f(t)`，丢掉的只是次数超过 N 的奇次正弦。以
`t = T/4` 这类连续点为例，实测误差为

| N | 3 | 10 | 50 | 100 |
|---|---|---|---|---|
| f(T/4) 的误差 | 1.5e−1 | 6.3e−2 | 1.3e−2 | 6.4e−3 |

大致按 `1/N` 下降，N 每翻一倍，连续点上的偏差就减半。

### 2. 跳变点附近的吉布斯现象

N ≥ 10 之后，过冲峰值随 N 变化是

```
1.1823  →  1.1791  →  1.1790
```

N 从 10 涨到 100（项数从 5 涨到 50，10 倍），过冲只降了 0.28%，并稳定收敛到理论极限

```
(2/π)·Si(π) = 1.1789797
```

即超出理想幅值 1 的部分恒为 `(1.1789797 − 1)/2 = 8.95%`（相对跳变幅度 2）。收敛是从上
方逼近的：N=10 高出极限 3.4e−3，N=50 高出 1.3e−4，N=100 只高出 3.3e−5。

N=3 那一格要单独说。它只有 2 项，波形整体是个圆钝起伏，还没形成平顶，表里的 1.2004 是
`sin(ω₀t) + sin(3ω₀t)/3` 自身的驻点，落在 `t = T/8`（解析上即 `cos ω₀t + cos 3ω₀t = 0`
的根 `ω₀t = π/4`）。跳变点前的局部峰值只有 1.1520，还没够到极限。所以 1.2004 不是吉布
斯过冲，从 N=10 起才是。

`f(t)` 在 `t = kT/2` 处有第一类间断点，其傅里叶级数在该点不连续，所以级数在 `[0, T]` 上
不是一致收敛的，只有均方收敛加上连续点上的逐点收敛。截断必然在间断点两侧留下振铃，
增加项数只能把振铃压到更窄的范围里，压不掉它的高度。

振铃的宽度确实在收窄。实测过冲点出现在跳变点之后约 `T/(2N)` 处，N=10、50、100 分别落在
距跳变点 0.050、0.010、0.005 处，与理论值逐位吻合。

跳变点本身（如 `t = 0`）级数收敛到左右极限的平均值 `0`，既不是 +1 也不是 −1，这是狄利
克雷条件的直接结论。脚本中 `f_approx(0)` 在各 N 下都恰好为 0，所以 2×2 子图在 t = 0 和
t = 3 处会看到一根从 0 拉起来的竖线，那是真实结果，不是画图错误。

### 3. 两种误差指标的下降速度为什么差很多

上表最后两列的量级完全不同。跳变点以外的最大偏差大致按 `1/N` 下降，N 从 50 到 100，
0.0974 → 0.0502，比值 0.52，接近减半。全区间 RMSE 只按 `1/√N` 下降，同样从 50 到 100，
项数翻倍，RMSE 才从 0.0902 降到 0.0639，降幅 29%。

差别在于残余误差的能量几乎全部集中在跳变点邻域。第 n 次谐波的幅值按 `1/n` 衰减，携带的
能量就按 `1/n²` 衰减；丢掉次数超过 M（`M = N`）的全部奇次项后，一个周期上的均方误差为

```
MSE = (4/π)² · (1/2) · Σ_{n 为奇数, n > M} 1/n²        (M = N)
```

开方得 `RMSE = (4/π)·√( ½ · Σ_{n 奇, n>M} 1/n² )`。当 M 较大时，剩下的尾巴 `Σ ≈ 1/(2M)`，
于是有更简单的渐近式

```
RMSE ≈ (2/π) / √M = (2/π) / √N
```

与实测对照（理论值按上式的精确形式逐项求和）：

| N | 3 | 10 | 50 | 100 |
|---|---|---|---|---|
| 理论 RMSE（精确求和） | 0.3152 | 0.2010 | 0.0900 | 0.0637 |
| 理论 RMSE（渐近式 `(2/π)/√N`） | 0.3676 | 0.2013 | 0.0900 | 0.0637 |
| 实测 RMSE | 0.3153 | 0.2011 | 0.0902 | 0.0639 |

精确求和的理论值与实测四组都吻合到 0.5% 以内。渐近式在 N ≥ 10 时误差已在 0.2% 量级，
N=3 时因为被丢掉的项太少而明显偏高，比精确值高出 17%。

N 从 50 增到 100 时项数翻了一倍，两幅图却几乎分不出来，原因就在这里：误差是按 `1/√N`
掉的。

想靠增加项数把 RMSE 再降一个数量级，需要把项数增加约 100 倍（N 取到 10000 量级），
代价是计算量、绘图量和跳变沿越来越扎眼的尖刺。工程上通常不这么做，而是改用别的手段
（对级数做算术平均即 Fejér 平均 / σ 近似等）来抑制吉布斯现象，这已超出本题范围。

## 三、关于第三问（N = 5）

按同一口径，`N = 5` 对应最高 5 次谐波，保留 `1、3、5` 共 **3 项**。

脚本画了两幅图，线型与颜色一一对应，可以对照着看：

**三维瀑布图**把每条谐波沿"谐波次数"轴分层摆放，z 轴是各自的瞬时值。这样一眼能看出两件事：

- 各次谐波的幅值是 `4/(πn)`，按 `1/n` 衰减——1 次谐波的振幅 1.273，5 次只有 0.255；
- 谐波次数越高，一个周期内振荡越密，正是这些高次分量把方角"垫"出来的。

合成波（黑实线）与周期矩形波（红虚线）放在最上层作对照：合成波是下面所有曲线逐点相加
的结果，它的方角处依然留着过冲。实测峰值 1.1884，即超出理想幅值 `(1.1884 − 1)/2 = 9.42%`
（相对跳变幅度 2），比第二节的渐近极限 8.95% 还高一些——只有 3 项时过冲尚未收敛到位，
项数越多越往下贴近 8.95%。

**二维叠加图**把全部波形画在同一坐标系里，靠线型区分：三条谐波分别用实线、虚线、点线并
配以三种不同颜色，合成波是加粗黑实线，矩形波是加粗红虚线。纵轴统一取 ±1.5，以便把基波
（振幅 1.273）和过冲都完整显示出来。

从二维图能直接读出"合成"这件事：基波定下轮廓，3 次谐波削出方角的雏形，5 次谐波把平顶段
再修平一些——每加一项，波形就离矩形近一步，但跳变点附近的过冲始终在。
