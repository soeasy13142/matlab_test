# 作业二 · 周期信号的傅里叶级数

周期信号的一个周期波形为

```
        ⎧ +1,  0 ≤ t < T/2
f(t) =  ⎨
        ⎩ -1,  T/2 ≤ t < T
```

周期为 `T`，基频 `ω₀ = 2π/T`。

## 一、傅里叶级数展开解析式

三角形式的傅里叶级数为

```
f(t) = a₀/2 + Σ [ aₙ·cos(nω₀t) + bₙ·sin(nω₀t) ]     n = 1, 2, 3, …
```

### 1. 先用对称性判断哪些项一定为零

- **奇函数**：周期延拓后 `f(-t) = -f(t)`（`t ∈ (-T/2, 0)` 段取值 `-1`，与 `t ∈ (0, T/2)`
  段的 `+1` 关于原点反对称）。奇函数不含余弦项，故 `a₀ = 0`，全部 `aₙ = 0`。
- **半波对称**：`f(t + T/2) = -f(t)`。这一条会消掉全部偶次谐波，只剩奇次。

两条对称性合起来说明：展开式里只有奇次正弦项。下面按定义严格算一遍，确认没有漏项。

### 2. 三个系数的积分

**直流分量**（注意一个周期内正负各占一半）：

```
a₀ = (2/T)∫₀ᵀ f(t) dt = (2/T)[ ∫₀^{T/2} 1·dt + ∫_{T/2}^{T} (-1)·dt ]
   = (2/T)( T/2 - T/2 ) = 0
```

**余弦项系数**：

```
aₙ = (2/T)[ ∫₀^{T/2} cos(nω₀t) dt − ∫_{T/2}^{T} cos(nω₀t) dt ]
   = (2/T)·(1/(nω₀))·{ [sin(nω₀t)]₀^{T/2} − [sin(nω₀t)]_{T/2}^{T} }
   = (2/T)·(1/(nω₀))·{ sin(nπ) − [ sin(2nπ) − sin(nπ) ] }
   = 0                                     （n 为整数时 sin(nπ) = sin(2nπ) = 0）
```

**正弦项系数**：

```
∫₀^{T/2}   sin(nω₀t) dt = (1 − cos nπ) / (nω₀)
∫_{T/2}^{T} sin(nω₀t) dt = (cos nπ − 1) / (nω₀)

bₙ = (2/T)[ ∫₀^{T/2} sin(nω₀t) dt − ∫_{T/2}^{T} sin(nω₀t) dt ]
   = (2/T) · 2(1 − cos nπ) / (nω₀)
```

代入 `nω₀ = 2πn/T`、`cos nπ = (−1)ⁿ`：

```
bₙ = 2(1 − (−1)ⁿ) / (πn)  =  ⎧ 4/(πn),  n 为奇数
                            ⎩ 0,        n 为偶数
```

### 3. 结果

```
           4   ∞      1
f(t)  =   ──  Σ    ────── · sin(nω₀t)          ω₀ = 2π/T
           π  n=1,3,5  n

          4 ⎡             1              1               ⎤
      =   ── ⎢ sin ω₀t + ── sin 3ω₀t + ── sin 5ω₀t + …   ⎥
          π ⎣             3              5               ⎦
```

幅值按 `1/n` 衰减，只含奇次谐波，这是双极性矩形波的标准展开式。

### 4. 数值核验

推导不靠手算结论。用基础 MATLAB 的 `trapz` 把 `[0, T/2]` 与 `[T/2, T]` 两段分开积分
（跳变点处切开，避免 `trapz` 跨越间断点），对 `n = 1…12` 逐项计算：

| n | 数值积分 aₙ | 数值积分 bₙ | 解析值 |
|---|---|---|---|
| 1 | 1.2e−16 | 1.273240 | 4/π = 1.273240 |
| 2 | 1.4e−17 | 0.000000 | 0 |
| 3 | 1.1e−16 | 0.424413 | 4/(3π) = 0.424413 |
| 4 | 0 | 0.000000 | 0 |
| 5 | 1.8e−16 | 0.254648 | 4/(5π) = 0.254648 |
| … | … | … | … |

`a₀ = 0`，全部 `aₙ` 都是 1e−16 量级的机器零，`bₙ` 与 `4/(πn)`（奇次）、`0`（偶次）
逐位吻合。解析式成立。

## 二、N 取 3、10、50、100 的差别及原因（研究与思考）

**本作业采用的口径**：截断到第 `2N+1` 次谐波，即保留 `n = 1, 3, 5, …, 2N+1`，
共 `N+1` 个非零项（偶数次项本来就是零，不占项数）。

脚本 `hw02_fourierSeries.m` 实测的四组指标（理想矩形波为参照）：

| N | 最高谐波 | 保留项数 | 过冲峰值 | 全区间 RMSE | 跳变点 0.02 s 外的最大偏差 |
|---|---|---|---|---|---|
| 3 | 7 | 4 | 1.1842 | 0.224575 | 0.394356 |
| 10 | 21 | 11 | 1.1797 | 0.135804 | 0.179668 |
| 50 | 101 | 51 | 1.1790 | 0.063318 | 0.048614 |
| 100 | 201 | 101 | 1.1789 | 0.045222 | 0.024524 |

### 1. 平缓段与跳变沿：N 越大越像矩形波

N=3 时波形还是圆钝的波浪，N=10 已能看出矩形轮廓，N=50、100 的平顶段几乎与理想
波形重合，跳变沿也从"斜坡"变成"陡壁"。

原因是级数在波形**连续**的点上逐点收敛于 `f(t)`。丢掉的项是 `n > 2N+1` 的奇次正弦，
在 `t = T/4` 这类连续点上，实测误差为

| N | 3 | 10 | 50 | 100 |
|---|---|---|---|---|
| f(T/4) 的误差 | 7.8e−2 | 2.9e−2 | 6.2e−3 | 3.2e−3 |

大致按 `1/N` 下降，所以项数加倍，连续点上的偏差就减半。

### 2. 跳变点附近的过冲不会消失 —— 吉布斯现象

这是四幅图之间**最本质**的区别。过冲峰值随 N 变化是

```
1.1842  →  1.1797  →  1.1790  →  1.1789
```

N 从 3 涨到 100（项数从 4 涨到 101，25 倍），过冲只降了 0.45%，并稳定收敛到理论极限

```
(2/π)·Si(π) = 1.1789797
```

即超出理想幅值 1 的部分恒为 `(1.1789797 − 1)/2 = 8.95%`（相对跳变幅度 2）。实测
N=100 的峰值 1.1789 与理论极限之差仅 −8e−5。

**原因**：`f(t)` 在 `t = kT/2` 处有第一类间断点，其傅里叶级数在该点不连续，因此级数
在 `[0, T]` 上**不一致收敛**，只有均方收敛加上连续点上的逐点收敛。截断必然在间断点
两侧留下振铃，增加项数只能把振铃压到更窄的范围里，压不掉它的高度。

振铃的宽度确实在收窄：实测过冲点出现在跳变点之后约 `T/(2(2N+1))` 处（N=100 时理论
0.00249，实测过冲落在 t = 1.49752，距跳变点 1.5 为 0.00248）。

还有一处细节：**跳变点本身**（如 `t = 0`）级数收敛到左右极限的平均值 `0`，既不是 +1
也不是 −1。这是狄利克雷条件的直接结论，脚本中 `f_approx(0)` 在各 N 下都恰好为 0，
所以 2×2 子图在 t = 0 和 t = 3 处会看到一根从 0 拉起来的竖线——那是真实结果，不是画图错误。

### 3. 两种误差指标为什么下降速度差很多

上表最后两列的量级完全不同：

- **跳变点以外的最大偏差**大致按 `1/N` 下降（N 从 50 到 100，0.0486 → 0.0245，正好减半）；
- **全区间 RMSE** 只按 `1/√N` 下降——N 从 50 到 100，项数翻倍，RMSE 才从 0.0633 降到
  0.0452，降幅 29%。

**原因**：残余误差的能量几乎全部集中在跳变点邻域。第 n 次谐波的幅值按 `1/n` 衰减，
所以它携带的能量按 `1/n²` 衰减；丢掉 `n > M`（`M = 2N+1`）的全部奇次项后，一个周期上
的均方误差为

```
MSE = (4/π)² · (1/2) · Σ_{n 为奇数, n > M} 1/n²        (M = 2N+1)
```

开方得 `RMSE = (4/π)·√( ½ · Σ_{n 奇, n>M} 1/n² )`。当 M 较大时，剩下的尾巴 `Σ ≈ 1/(2M)`，
于是有更简单的渐近式

```
RMSE ≈ (2/π) / √M = (2/π) / √(2N+1)
```

与实测对照（理论值按上式的精确形式逐项求和）：

| N | 3 | 10 | 50 | 100 |
|---|---|---|---|---|
| 理论 RMSE（精确求和） | 0.2245 | 0.1357 | 0.0630 | 0.0448 |
| 理论 RMSE（渐近式 `(2/π)/√(2N+1)`） | 0.2406 | 0.1389 | 0.0633 | 0.0449 |
| 实测 RMSE | 0.2246 | 0.1358 | 0.0633 | 0.0452 |

精确求和的理论值与实测四组都吻合到 1% 以内（差值来自离散采样对跳变沿附近尖峰的分辨
能力）。渐近式在 N ≥ 50 时误差已在 0.1% 量级，N=3 时因为被丢掉的项太少而偏差较大。

这也解释了一个反直觉的现象：**N 从 50 增到 100，项数翻了一倍，但肉眼几乎分不出这两幅图**
—— 误差是按 `1/√N` 掉的。

想靠增加项数把 RMSE 再降一个数量级，需要把项数增加约 100 倍（N 取到 10000 量级），
代价是计算量、绘图量和跳变沿越来越"扎眼"的尖刺。工程上通常不这么做，而是改用别的手段
（对级数做算术平均即 Fejér 平均 / σ 近似等）来抑制吉布斯现象，这已超出本题范围。

### 4. 小结

| 观察 | 结论 |
|---|---|
| 平顶段、跳变沿越来越准 | 连续点上逐点收敛，误差约按 `1/N` 下降 |
| 过冲峰值稳定在 1.179，不随 N 减小 | 吉布斯现象：间断点处不一致收敛，超调恒为 8.95% |
| 振铃宽度随 N 收窄 | 宽度约 `T/(2(2N+1))` |
| 全区间 RMSE 按 `1/√N` 下降 | 残余能量集中在跳变点邻域，只能缓慢下降 |
| 跳变点上收敛到 0 | 狄利克雷条件：收敛到左右极限的算术平均 |

## 三、关于第三问（N = 5）

按同一口径，`N = 5` 对应最高 `2N+1 = 11` 次谐波，保留 `1、3、5、7、9、11` 共 **6 项**。

脚本画了两幅图，线型与颜色一一对应，可以对照着看：

**三维瀑布图**把每条谐波沿"谐波次数"轴分层摆放，z 轴是各自的瞬时值。这样一眼能看出两件事：

- 各次谐波的幅值是 `4/(πn)`，按 `1/n` 衰减——1 次谐波的振幅 1.273，11 次只有 0.116；
- 谐波次数越高，一个周期内振荡越密，正是这些高次分量把方角"垫"出来的。

合成波（黑实线）与周期矩形波（红虚线）放在最上层作对照：合成波是下面所有曲线逐点相加
的结果，它的方角处依然留着 8.95% 的过冲，原因见第二节。

**二维叠加图**把全部波形画在同一坐标系里，靠线型区分：六条谐波用实线 / 虚线 / 点线 /
点划线循环并配以六种不同颜色，合成波是加粗黑实线，矩形波是加粗红虚线。纵轴统一取
±1.5，以便把基波（振幅 1.273）和过冲都完整显示出来。

从二维图能直接读出"合成"这件事：基波定下轮廓，3 次谐波削出方角的雏形，5 次及以上
的谐波把平顶段一点点修平——每加一项，波形就离矩形近一步，但跳变点附近的过冲始终在。
