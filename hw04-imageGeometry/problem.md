# 第四部分 工程软件应用能力——在数字图像处理中的应用

## 实践内容：图像的几何运算

通过查询 MathWorks 支持站点：https://ww2.mathworks.cn/help/matlab/index.html 或 MATLAB 的 help：

### 1、基础要求

#### （Ⅰ）学习改变图像的大小的方法

学习 MATLAB 中 `imread`、`imresize`、`imshow` 的功能及使用方法。

#### （Ⅱ）学习旋转一幅图像的方法

MATLAB 图像处理工具箱利用函数 `imrotate` 对图像进行旋转操作，其一般的调用格式为：

```matlab
B = imrotate(A,angle)；
B = imrotate(A,angle,method)。
```

其中 A、B 分别为输入、输出图像；

`angle` 为逆时针旋转的角度，`angle` 为负时，表示顺时针旋转；

`method` 是旋转过程中使用的插值方法，可以是 `nearest`（最近邻插值）、`bilinear`（双线性插值）或 `bicubic`（双立方插值），默认的插值方法是最近邻插值。旋转操作会使图像尺寸变大，`imrotate` 对原图像边界之外的像素用 0 填充，显示的是黑色的背景。

`crop` 是可选参数，用来自动剪切旋转后比原图像多出的部分。

#### （Ⅲ）学习图像剪切的方法

通过图像的裁剪操作能够得到图像的部分图，MATLAB 图像工具箱利用函数 `imcrop` 实现图像的裁剪，其一般的调用格式为：

```matlab
I2 = imcrop(I,rect)；
X2 = imcrop(X,map,rect)；
RGB2 = imcrop(RGB,rect)。
```

上述三种调用格式分别用于灰度图（包括二值图）、索引图和 RGB 图的裁剪。

### 2、提高要求（加分选做部分）

1. 建议梳理本科阶段图像处理课程的核心知识点，确定平台展示的算法。至少包含图像几何变换、灰度变换、直方图均衡化、空域滤波、频域滤波、边缘检测、阈值分割、特征提取等，每一类算法至少要有 2 种实现方法，并验证算法的正确性。

2. 运用 MATLAB 编程设计功能完善的图像处理实验平台。平台可视化交互界面可选用 MATLAB App Designer 或 GUI 设计。实现图像管理、算法操作、参数调节、结果展示等。

3. 图像格式兼容性，至少支持 `BMP`、`JPG/JPEG`、`PNG`、`TIFF`、`GIF` 格式图像导入/导出。对于小于 4096×4096 分辨率图像导入成功率 100%，无格式解析错误。处理后图像保存无像素丢失、格式损坏等。

4. 设计的实验平台各个算法输出的结果与 MATLAB 图像处理工具箱中函数输出结果视觉无明显差异。

5. 自动化实验步骤记录、处理结果对比、实验报告自动生成功能。
